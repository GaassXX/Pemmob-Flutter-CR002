## 📱 Panduan Cara Mencoba Prototype

Ikuti langkah-langkah berikut untuk menguji alur aplikasi:

1. **Buka Tautan Prototype:**
   * Klik link [Figma Prototype](https://bugle-equity-84090280.figma.site) di browser Anda (disarankan menggunakan Google Chrome atau browser modern di Desktop/Laptop untuk tampilan yang optimal).
2. **Halaman Autentikasi / Login:**
   * Pada kolom input email, masukkan: `admin@admin.com`
   * Pada kolom input kata sandi, masukkan: `password`
   * Klik tombol **Masuk / Login** untuk dialihkan ke menu utama.
3. **Eksplorasi Fitur FinChat:**
   * **Dashboard / Beranda**: Melihat ringkasan total saldo, diagram arus kas (pemasukan vs pengeluaran), dan riwayat transaksi terbaru.
   * **Chat Bot**: Mencoba alur simulasi pencatatan keuangan dan navigasi interaktif melalui antarmuka percakapan bot sistem.
   * **Manajemen Dompet / Rekening**: Melihat daftar alokasi dana, sumber keuangan, dan kategori anggaran.
   * **Profil & Pengaturan**: Melihat pengaturan profil pengguna serta preferensi tampilan antarmuka.
4. **Petunjuk Interaksi Figma:**
   * Klik di sembarang area layar pada prototype Figma untuk menampilkan *blue hotspot highlight* (area tombol atau kartu yang dapat diklik/diinteraksikan).

## 📌 Catatan Penting & Penjelasan Pengembangan

> [!IMPORTANT]
> **1. Karakteristik Fitur Bot (Bot Biasa, Bukan AI):**
> Fitur percakapan pada aplikasi FinChat merupakan **bot sistem otomatis biasa (*rule-based / template-driven bot*)**, **BUKAN** berbasis *Artificial Intelligence* (AI) maupun *Large Language Model* (LLM). Bot ini berfungsi sebagai asisten alur interaktif terprogram untuk memandu pencatatan keuangan secara terstruktur melalui percakapan.

> [!NOTE]
> **2. Status Pengembangan Aktif & Fleksibilitas UI/UX:**
> Aplikasi dan prototype ini masih berada dalam **tahap pengembangan aktif (*active development*)**.
> * Seluruh komponen tampilan antarmuka (*User Interface / UI*), tata letak komponen, alur pengguna (*User Experience / UX*), hingga kelengkapan fitur dapat **berubah sewaktu-waktu**.
> * Perubahan akan terus disesuaikan berdasarkan umpan balik (*feedback*), evaluasi pengujian, serta kebutuhan riil pengguna (*user needs*) yang menggunakan aplikasi ini di masa mendatang maupun batasan teknis saat implementasi ke Flutter.
